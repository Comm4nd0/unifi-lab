# UniFi Virtual Lab

A web-based, protocol-faithful simulator for UniFi networks.

- **Project status:** pre-alpha (Phase 0 — protocol round trip in progress).
- **Repository:** <https://github.com/Comm4nd0/unifi-lab>
- **Licence:** MIT (code), CC BY 4.0 (docs).

See the repo [`README`](https://github.com/Comm4nd0/unifi-lab#readme) and
[`CLAUDE.md`](https://github.com/Comm4nd0/unifi-lab/blob/main/CLAUDE.md)
for orientation.

## Roadmap

1. Phase 0 — protocol round trip
2. Phase 1 — single device web UI
3. Phase 2 — fleet and firmware library
4. Phase 3 — traffic simulation
5. Phase 4 — integration and polish
6. Phase 5 — Flutter mobile viewer

Authoritative design lives in the Obsidian vault.
